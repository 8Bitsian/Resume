# Projects
The following projects are all open-source and available on my [GitHub]().

## OpenSky • Weather Forecast Desktop Application
[GitHub Repository]() • Aug 2026 - Present</br>
A Python desktop application for Linux/Windows users that retrieves weather data from the OpenWeatherMap API.
- Built the interface with PyQt6 and QSS
- Integrated the OpenWeatherMap API to retrieve weather data
- Designed a clear interface for viewing real-time weather information
- Demonstrates desktop GUI development, API integration, and user-focused design

## OpenSupport • Community Supply Coordination Tool
[GitHub Repository]() • Oct 2026 - Present</br>
A Python web application for nonprofits to tract requested and available supplies - such as food, hygiene kits, blankets, etc. - and identify shortages to post notifications for support.
- Built a REST API with FastAPI and PostgreSQL
- Add CSV import/export, inventory updates, and reports by item or location
- Demonstrates API development, data validation, and reporting

## OpenWallet • Personal Finance Tracker Desktop Application
