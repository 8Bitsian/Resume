I recently switched my main HP desktop over from Windows 11 to Linux Mint Cinnamon Edition, and have to say that I am impressed by the considerable upgrade in quality of user expereince I have had using this Linux Distro.

For context, I had originally switched to Linux Mint for an old HP 14-dq0000dx model laptop that originally ran Windows 11 to try and salvage it since the RAM was soldered on an non-upgradable, which I felt is a predatory practice in nature, but I digress.
I talked further in depth on the reasoning behind choosing this Linux distribution in a [previous article](https://8bitsian.github.io/Resume/2026/07/28/Switching-to-Linux-Operating-System.html).

Later on, I switched an old ThinkCentre Edge all-in-one desktop PC over to Linux Mint XFCE Edition as well and now use it for class work or to test experimental features without risking my main PC.

Just this month, my grandfather had given me a 1TB SSD and so I finally bit the bullet and downloaded any files I hadn't uploaded to the cloud and switched over my main desktop PC over to Linux Mint Cinnamon Edition.

The reason being it that my main desktop had the hardware necessary to be able to handle the more resource intensive OS.

It has been over two weeks since I switched all of my PCs to Linux Mint and the difference between Windows 11 and Linux is night and day, especially for my experience with how I use my main desktop.
